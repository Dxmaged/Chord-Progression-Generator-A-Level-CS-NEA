This is my A-Level Computer Science Coursework

I used django a high-level Python web framework to create a website which takes in parameters from the user such as the tonic, genre, instrument etc.

It then puts these parameters into an algorithm coded in python that generates a chord progression based on the inputs

After the progression is made I then used javascript to pull from an api (https://www.scales-chords.com) which allowed me display piano or guitar tabs for the chords as well as add audio files for said chords.
